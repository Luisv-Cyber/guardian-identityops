# Security

This is a simulated lab environment (Guardian Financial Technologies is a fictional company). Even so, this repository follows the same handling rules that would apply to a real environment.

## Never Committed to This Repository

* Passwords or temporary passwords
* Microsoft Entra tenant IDs
* Azure subscription IDs
* Public IP addresses
* Personal email addresses
* Client secrets, access tokens, refresh tokens, or API keys
* Private keys or certificates
* Any real personal information

## Handling Screenshots and Evidence

Any screenshot added to [`screenshots/`](screenshots/) must first be reviewed and redacted for all of the items above. See [`screenshots/README.md`](screenshots/README.md) for the reserved filenames and what each documents.

## Sample Data

[`sample-data/employees.example.csv`](sample-data/employees.example.csv) contains fictional identities only, used to illustrate the schema and the validated Joiner/Mover/Leaver test scenarios. It is not the original working dataset and contains no real personal information.

## Reporting

This is a personal portfolio project with no production users or data. There is no formal disclosure process — if you notice something that shouldn't be here, feel free to open an issue.
